# はじめての麻雀道場

リーチ麻雀を基礎から学べる学習＆対戦ゲーム（ブラウザで動く。iPhone 縦画面向け）。

- 遊ぶ: `index.html` を開く（GitHub Pages で公開予定）
- テスト: `./devtests/run.sh`（macOS の jsc で動く。インストール不要）

## 作る順番
1. 1人で牌を引いて捨てて和了判定 ← いまここ
2. 4人対局（鳴きなし）
3. 鳴き・リーチ・役・点数計算
4. ヒント機能・レッスン・ドリル
5. チャレンジ・役図鑑・成績など

## ファイル
- `core/` 画面に依存しない計算（牌・山・和了判定・シャンテン数など）。テストの対象
- `ui/` 画面
- `devtests/` テスト
